## 핵심 인사이트

1. **"공동수급" 키워드 전용 카페는 사실상 없음**. 공동수급/컨소시엄 모집은 별도 카페 카테고리가 아니라 **건설입찰정보동호회·조달파워·입찰제안서연구소** 같은 종합 입찰 카페의 게시판에서 다뤄짐. 따라서 다음 사이클의 "모집/공고" 글 스캔은 이들 카페의 자유게시판/공동도급 게시판을 노려야 함.
2. **검색 노이즈가 매우 큼** — "공공입찰" 검색 결과 상당수는 회원 7~14명짜리 동일 템플릿 스팸 카페("나라장터·조달청·공공입찰 실무자들의 No.1 커뮤니티!" 류). 멤버수 정렬 + 새글수 확인이 필수.
3. **사이드 광고 분석으로 확인된 경쟁 SaaS**: 케이비드(kbid.co.kr), 21라인(21line.co.kr), (주)비드메이트 — 이들은 자체 카페 + 자체 입찰분석 SaaS를 같이 운영하므로 본 프로젝트의 직접 경쟁군. 카페는 마케팅 채널 + 사용자 풀로 보임.

## 우선순위 추천 (사용자 가입 순서)

본 프로젝트 목적(공동수급 모집/입찰 노하우/사전규격 토론 발굴) 기준 가입 권장 순:

1. **조달파워** (jodalpower) — 회원 28K, **가지3단계** = 카페 등급이 가장 높음 = 가장 활성. "조달입문 정보공유 1등" 표방. 나라장터 입문자~중급자 풀 보유. **최우선 가입.**
2. **건설입찰정보동호회** (bidmaster) — 회원 16K. 카페 소개에 "전자입찰/입찰/낙찰/**공동도급**/나라장터/투찰율/발주계획" 명시. 공동수급 모집 글이 가장 많을 가능성.
3. **입찰제안서 연구소 BIDLAB** (hack100000) — 회원 42K(최대). 다만 "씨앗4단계"라 등급 대비 회원수가 큼 → 게시글 1줄짜리·낚시성 의심. 가입 후 게시판 구성 직접 확인 필요.
4. **건설의 모든것** (igunsul) — 회원 11K, **새글 10** (Tier1 중 가장 활성). 건설업 종합이라 입찰 비중은 일부지만 공동수급 사례 풍부 가능.
5. **조달+** (vs777sv) — 회원수는 작지만 카페 이름 자체가 "나라장터 입찰·낙찰·**수주** 정보 커뮤니티". 사례 중심 콘텐츠 가능성.
6. (선택) **메이저위드** (mmc9001) — 우수제품·KS·NEP 인증 특화. 본 프로젝트의 "사전규격" 토론 영역과 맞음.

> **Note**: 가입 후 등업 조건이 까다로운 카페가 일반적(자기소개+활동 N회). 등업 전엔 게시판 일부만 열람 가능 → 다음 사이클 스캔 범위는 등업 상태에 따라 조정.

## 다음 단계 (Phase 2 — 게시글 스캔 사이클)

진입 조건: 사용자가 위 우선순위 1~3번 중 최소 1개 카페에 가입(가능하면 등업까지) 완료.

진행 시퀀스:
1. **게시판 매핑** — 가입한 카페별로 메인 화면(`cafe.naver.com/{cafeId}`)에서 좌측 게시판 트리 스냅샷, 다음 게시판 우선:
   - 자유게시판/Q&A (모집·구함 글이 흩어짐)
   - 공동도급/공동수급/컨소시엄 전용 게시판 (있을 경우)
   - 공고/사전규격 게시판
   - 정보공유 게시판
2. **최근 7일 글 목록 추출** — 각 게시판 첫 페이지(보통 20~50개) 스냅샷, 작성일 7일 내 필터.
3. **키워드 매칭** — 제목 OR 본문 첫 줄에 다음 중 1개 이상:
   `모집`, `공고`, `입찰`, `낙찰`, `공동수급`, `공동도급`, `컨소시엄`, `구함`, `구합니다`
4. **매칭 글 본문 수집** — 매칭된 글만 클릭 → 본문 스냅샷 → 마크다운 변환.
5. **산출물**: `docs/research/naver-cafe-recruits-{YYYYMMDD}.md`
   - 카페별 섹션, 글 단위 표(제목/작성일/카테고리/요약/원문 URL)
6. (Phase 3 예고) 패턴 안정화되면 SQLite `cafe`, `cafe_post`, `recruit_signal` 테이블 설계 — `data-modeler` 에이전트 위임.

호출 간격 권장: 카페 진입 사이 3초, 본문 클릭 사이 2초. 세션 차단 위험 감지 시 즉시 중단 후 사용자에게 보고.

## 주의 / 한계
