# Sion Lab 프로필 (입찰 매칭용)

> 본 문서는 KONEPS_sionlab 워크스페이스에서 나라장터 입찰을 매칭·추천할 때 **고정 기준**으로 사용한다.
> 출처: `https://sionlab.co.kr` + `~/projects/Sionlab*` 로컬 폴더 종합 (2026-05-08 확정).

## 회사 정체성

**Sion Lab (시온랩)** — AI 기반 데이터 자동화 + API 마켓플레이스 + 산업안전 컨설팅을 운영하는 소규모 기술 솔루션 기업.

> "Claude · Codex · Cursor 코드 에이전트로 일하는 방식을 사람에게 이전한다."

## 핵심 제품·역량

| 제품 | 설명 |
|---|---|
| **S-Market** | 연계 데이터 카탈로그 110+종 API 마켓플레이스 (하이픈/CODEF 영역) |
| **S-Build** | 현장 워크플로우 설계, 맞춤형 ERP·CRM 구축 |
| **S-Agent** | Claude/Codex/Cursor 기반 AI 코드 에이전트 운영·이전 |
| **S-Docs / OCR** | 한국어 PDF OCR (RapidOCR + LLM 검증), 문서 디지털화 |
| **Safety Consulting** | 산업안전 진단/교육/법규 자문 (자회사 라인) |

## 타겟 도메인

- **B2B**: 제조, 금융, 부동산, 유통, 법률 산업 현장 중소기업·운영조직
- **B2G (신규 타겟)**: 공공기관 문서 디지털화, API 통합, 안전 의무 컨설팅
- 회사 규모상 **5천만~5억원대** 사업 적합. 폐쇄망(VPC/온프레미스) 영업 가능.

## 입찰 매칭 키워드 (가중치)

| 키워드 | 가중치 | 비고 |
|---|---|---|
| `OCR` | 3.0 | 핵심 차별화 |
| `문서인식`, `문서 자동화` | 2.5 | OCR 동의어군 |
| `AI`, `인공지능` | 2.0 | 광범위 매칭, 노이즈 주의 |
| `데이터 자동화`, `업무자동화`, `RPA` | 2.0 | S-Build 영역 |
| `API`, `데이터 연계`, `오픈API` | 1.8 | S-Market 영역 |
| `ERP`, `CRM`, `시스템 구축` | 1.5 | 맞춤 구축 |
| `산업안전`, `안전컨설팅`, `안전관리` | 1.5 | Safety Consulting |
| `이미지 인식`, `컴퓨터비전` | 1.2 | 인접 기술 |

**기관 보너스 (+1.0)**: NIA, KISA, 한국지능정보사회진흥원, 우정사업본부, 시·도 교육청, 국세청, 조달청 등 디지털 친화 발주처.

**예산 보너스 (+1.0)**: 5천만 ~ 5억원 구간.

## department_profile (자연어, MCP 입력용)

`recommend_bids_for_dept(department_profile=...)` 호출에 그대로 복사:

```
한국어 OCR과 LLM 기반 문서 자동화, ERP·CRM 맞춤 구축, 공공 API 통합 마켓플레이스(S-Market), AI 코드 에이전트(S-Agent) 운영, 산업안전 컨설팅을 제공하는 소규모 기술 솔루션 팀. 제조·금융·부동산·유통·법률 산업의 운영 자동화와 공공기관 문서 디지털화 사업에 적합.
```

## 사용 규칙

- 모든 입찰 점수는 위 키워드 가중치 합 + 기관/예산 보너스로 계산.
- 사용자(=대표) 직접 영업 가능 규모(5천만~5억원)를 우선.
- 60억원 이상 대형 SI는 Sion Lab 단독 수주 비현실적 → 점수 하향(-2.0).
